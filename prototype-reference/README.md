# Browser prototypes — unchanged reference copies

Open `V8.1-Simple-Review.html` for the latest simplified six-workspace prototype. Use `V8-60-Screen-Reference.html` only for deeper historical workflow reference. Both files are copied byte-for-byte from earlier delivered HTML; no prototype redesign or UE implementation was performed in this packaging task.

V8.1 is a schematic in-memory review tool, not Landscape integration, mesh generation or traffic simulation. Its lane query is a limited forward example, its 3D transform inputs are not a fully rendered banked frame and most service access is illustrative. Reload does not provide production recovery. Real undo/redo, durable persistence, mesh/graph compilation and runtime behavior belong to the five implementation phases.

The complete earlier prototype ZIPs with all screenshots/test tooling are not duplicated here. The original Markdown/text documents and JSON reports/fixtures are preserved under `references/`; image links and historical test commands there may require the original prototype packages. Historical results were not rerun by copying files.
